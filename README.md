## 📌 Overview

This project aims to predict laptop prices based on specifications like **RAM**, **GPU**, **CPU**, **screen resolution**, and **weight**. Using a **Random Forest Regressor**, we train a model capable of delivering high-accuracy predictions after proper data preprocessing.

---

## 🚀 Features

- 🔄 **Data Preprocessing**: Handling missing values, cleaning columns, encoding.
- 🌲 **Machine Learning Model**: Random Forest Regressor for robust predictions.
- 📊 **Visualizations**: Matplotlib and Seaborn for feature analysis and model evaluation.
- 📈 **Power BI Dashboard**: (Optional) For executive-level interactive reporting.
- 🖥️ **Web App**: (Optional) Streamlit app for real-time predictions.

---

## 📂 Dataset

The dataset includes **1300+ laptop records** with details such as:

- 🏷 **Company**: Apple, Dell, HP, Lenovo, etc.
- 💻 **Type**: Ultrabook, Notebook, Gaming, etc.
- 📊 **Specs**: RAM (GB), GPU, CPU, ScreenResolution
- ⚖️ **Weight**: In kilograms
- 🖥 **OS**
- 💰 **Price**: (Target variable)
